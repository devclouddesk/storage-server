# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The DevCloudDesk team takes security issues very seriously.

If you discover a security vulnerability in DevCloudDesk Storage Server, please **DO NOT** open a public issue. Instead, report it privately:

- **Email**: security@devclouddesk.com
- **Response Time**: We acknowledge receipt of vulnerability reports within 48 hours.

Please include:
- A detailed description of the vulnerability.
- Steps to reproduce or proof-of-concept code.
- Impact assessment.

We will coordinate a fix and release a security advisory before disclosing the issue publicly.
